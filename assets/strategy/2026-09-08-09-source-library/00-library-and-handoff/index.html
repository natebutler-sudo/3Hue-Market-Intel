How to use this

Keep the files together in one folder and open index.html — this page — by double-clicking it. Every link below opens the document in the same browser window. Works on Windows, macOS, Linux, iOS and Android, online or offline, on a USB stick or in a shared drive.

Each document is a single self-contained file: the fonts are embedded inside it, so a document still reads correctly if you email just that one file to someone. Print or save to PDF from the browser — every document carries a print stylesheet that unrolls the wide tables and drops the sidebar navigation. Finished PDFs of all 18 are in the pdf/ folder.
