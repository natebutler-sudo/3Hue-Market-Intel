3HUE · SharePoint marketing library · v1 · September 2, 2026

The Marketing
Folder

12 parents, 86 folders, three levels deep — shallow enough that OneDrive sync never breaks.

Design rulesNumbered parents so sort order is deliberate. Maximum three levels. Hyphens, never spaces. Nothing named "Misc," "New folder" or anyone's initials.
Create now vs laterBuild every parent immediately — empty parents prevent people inventing their own. Only populate subfolders where something exists to put in them.
The one ruleIf you cannot decide where a file goes in ten seconds, the structure is wrong and should be fixed. Do not create a new top-level folder to resolve it.

Each parent has one job. Where a folder maps to something already built, the note says so; where it is empty on purpose, the note says what belongs there when it exists.

02

Naming files

Four rules. They exist so that sorting works, search works, and nobody opens a folder containing final-FINAL-v2-USE-THIS.pptx.

RuleDoNot
Dates first, ISO format
For anything time-bound: campaigns, reports, decks for a specific meeting.		2026-09-02-blocked-deal-brief.docxSept 2 brief.docx
09-02-26 brief.docx
Hyphens, not spaces
Spaces become %20 in URLs and eat the path budget.		message-stack-v1.htmlMessage Stack v1.html
Let SharePoint version it
Version history is built in. Only version in the filename when the versions are genuinely different artifacts.		pitch-deck-regulated.pptx
pitch-deck-saas.pptx		pitch-deck-v7-final.pptx
No client names without consent
Filenames are visible in search and link previews. Consent lives in 10_Legal.		case-study-transit-technologies.docx (consented)case-study-large-bank-DO-NOT-SHARE.docx

Characters SharePoint will reject or mangle: " * : < > ? / \ | and leading or trailing spaces. # and % work now but still break older integrations. Ampersands survive but complicate links. Stick to letters, numbers and hyphens.

03

Where does this go?

The questions that actually cause hesitation, answered once so the structure holds after the first month.

If it is…It goes inBecause
Approved copy used across many places03_MessagingMessaging is the source; campaigns borrow from it, never the reverse.
Copy written for one campaign only04_Campaigns/Active/…/2-CopyIt dies with the campaign. Keeping it central creates conflicting versions.
An asset a seller opens during a call06_Sales-EnablementIf a seller has to think about which folder, they will improvise instead.
A logo, template or font02_BrandOne place, read-only for most people.
A statistic or its source PDF03_Messaging/Claims-Library-and-EvidenceClaim and evidence live together, or the evidence is gone when you need it.
A signed client permission10_Legal-and-Compliance/Client-ConsentsRestricted, and findable in one place when someone asks whether you can publish.
A prospect list or target account file07_Demand-Engine/Target-ListsPersonal data. Keep it out of general-access folders and mind retention.
Something superseded but not worthless11_Archive/YYYYMove, do not delete. Deleting in anger is how institutional memory disappears.
Genuinely none of the aboveAsk, then fix the structureA new top-level folder is almost never the answer. Two people inventing folders is how this collapses.

05

SharePoint specifics

Path length is the failure mode that catches everyone

SharePoint allows about 400 characters for the full encoded URL, and OneDrive sync starts failing well before that. This structure is deliberately three levels deep, with the longest folder path at 47 characters — leaving roughly 250 for the site URL, the campaign subfolder and the filename. That headroom is the reason not to add a fourth level later.

SettingRecommendationWhy
PermissionsEveryone: read on all, write on 03 through 07. Restrict 10_Legal-and-Compliance to Andrew plus one. Make 02_Brand read-only for most.Brand files get "improved" by well-meaning people. Legal files should not be browsable.
VersioningOn, major versions, keep 50.Removes the need for version numbers in filenames and makes "who changed this" answerable.
Sync vs browserSync 02_Brand and the active campaign only.Syncing everything is how people hit path limits and fill laptops.
Metadata columnsSkip for now. Revisit only if search starts failing.Purists prefer metadata to folders. Small teams reliably ignore metadata and use folders anyway. Build what people will use.
Retention on target listsSet a review date on 07_Demand-Engine/Target-Lists.Those files hold personal data. Keeping prospect lists indefinitely is a GDPR problem for a firm that sells compliance.
External sharingOff by default. Share individual files, never folders.A shared folder link grants access to everything added later, which is rarely what anyone intended.
